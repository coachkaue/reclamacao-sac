Use os botões abaixo para alternar entre a visualização de processo detalhado e a sequência cronológica de rede. Clique em "Imprimir / Salvar PDF" para gerar um arquivo PDF de alta resolução.

    classDef stepClass fill:#f9fafb,stroke:#d1d5db,stroke-width:2px,color:#1f2937;
    classDef decisionClass fill:#e0f2fe,stroke:#0284c7,stroke-width:2px,color:#0369a1;
    classDef actionClass fill:#f0fdf4,stroke:#16a34a,stroke-width:2px,color:#15803d;
    classDef errorClass fill:#fef2f2,stroke:#dc2626,stroke-width:2px,color:#991b1b;
    classDef startClass fill:#0c2340,stroke:#0c2340,color:white,font-weight:bold;

    Start([Início: Cidadão acessa o site]):::startClass --> Step1[Etapa 1: Categoria de Serviço]:::stepClass
    
    Step1 --> ChoiceService{Serviço == Cartão?}:::decisionClass
    ChoiceService -->|Sim| ShowBandeira[Exibe campo Bandeira do Cartão]:::stepClass
    ChoiceService -->|Não| HideBandeira[Mantém oculto e desabilitado]:::stepClass
    
    ShowBandeira & HideBandeira --> Next1[Botão Avançar]:::stepClass
    Next1 --> Step2[Etapa 2: Dados do Consumidor]:::stepClass
    
    Step2 --> TypingCPF[Digitação CPF & Telefone]:::stepClass
    TypingCPF --> MaskApply[Máscaras em tempo real aplicadas no input]:::stepClass
    MaskApply --> Next2[Botão Avançar]:::stepClass
    Next2 --> ValidCPF{Algoritmo CPF é válido?}:::decisionClass
    ValidCPF -->|Não| ErrorCPF[Exibe erro e bloqueia avanço]:::errorClass
    ValidCPF -->|Sim| Step3[Etapa 3: Dados do Fornecedor]:::stepClass
    
    ErrorCPF --> TypingCPF
    
    Step3 --> InputFornecedor[Preenche dados do SAC / Protocolo]:::stepClass
    InputFornecedor --> Next3[Botão Avançar]:::stepClass
    Next3 --> Step4[Etapa 4: Questionário & LGPD]:::stepClass
    
    Step4 --> CheckList[Responde 13 perguntas de conformidade]:::stepClass
    CheckList --> ConsentLGPD{Marcou aceite da LGPD?}:::decisionClass
    
    ConsentLGPD -->|Não| BlockSubmit[Bloqueia envio e exibe alerta]:::errorClass
    ConsentLGPD -->|Sim| ClickSubmit[Botão Enviar Reclamação]:::stepClass
    
    BlockSubmit --> Step4
    
    ClickSubmit --> Loading[Exibe tela de processamento: Enviando...]:::actionClass
    
    Loading --> FetchSend[Angular envia POST text/plain com chaveSeguranca]:::actionClass
    
    FetchSend --> GAS_Recv[Google Apps Script recebe JSON]:::actionClass
    
    GAS_Recv --> AuthCheck{chaveSeguranca == Token Requerido?}:::decisionClass
    AuthCheck -->|Não| Res403[Retorna Erro 403: Acesso não autorizado]:::errorClass
    AuthCheck -->|Sim| ServerValid{CPF & Obrigatórios Preenchidos?}:::decisionClass
    
    ServerValid -->|Não| Res400[Retorna Erro 400: Dados ausentes ou CPF inválido]:::errorClass
    ServerValid -->|Sim| GenProtocol[Gera Protocolo: PROCON-ANO-RANDOM]:::actionClass
    
    GenProtocol --> Sanitize[Higieniza campos de texto: Previne XSS]:::actionClass
    Sanitize --> WriteSheet[Escreve linha na planilha: Coluna A a AA - Protocolo na AA]:::actionClass
    WriteSheet --> Res200[Retorna status: success e protocolo]:::actionClass
    
    Res200 & Res400 & Res403 --> AngularHandler{Status da Resposta}:::decisionClass
    
    AngularHandler -->|Sucesso| SuccessScreen[Exibe tela verde de Sucesso com Protocolo Oficial]:::actionClass
    AngularHandler -->|Erro| ErrorScreen[Exibe alerta de erro na tela e libera botão para reenvio]:::errorClass
    
    SuccessScreen --> Reset[Botão Novo Registro limpa formulário]:::stepClass
    Reset --> Step1
        
sequenceDiagram
    autonumber
    actor Cidadao as Cidadão (Navegador)
    participant Angular as Formulário Angular (Frontend)
    participant API as Google Apps Script (Backend)
    participant Planilha as Google Sheets (Planilha)

    Cidadao->>Angular: 1. Preenche o formulário (Etapas 1 a 4)
    Note over Angular: O Angular formata o telefone e valida o CPF digitado
    
    Cidadao->>Angular: 2. Aceita a LGPD e clica em "Enviar"
    
    Angular->>API: 3. Envia os dados + Token Secreto de Segurança
    
    Note over API: O Google valida o Token Secreto (Anti-Spam)
    Note over API: O Google limpa os textos contra hacks (Anti-XSS)
    Note over API: O Google gera o número de Protocolo Oficial
    
    API->>Planilha: 4. Grava a linha na planilha (colunas A a Z) + Protocolo (coluna AA)
    Planilha-->>API: 5. Confirmação de gravação
    
    API-->>Angular: 6. Devolve resposta de Sucesso + Protocolo Oficial
    
    Angular-->>Cidadao: 7. Exibe a tela verde com o número do Protocolo

    Start(["Início: Fiscal acessa a Área do Fiscal"]):::startClass --> LoadPage["Sistema carrega página administrativa /fiscal"]:::stepClass
    
    LoadPage --> FetchList["Angular faz requisição GET para Google Apps Script"]:::actionClass
    
    FetchList --> GAS_List["Apps Script lê a Planilha Google"]:::actionClass
    GAS_List --> ReadAllRows["Lê todas as reclamações registradas"]:::actionClass
    ReadAllRows --> ReturnJSON["Retorna lista JSON com todas as reclamações"]:::actionClass
    
    ReturnJSON --> RenderTable["Angular renderiza a tabela cronológica das reclamações"]:::stepClass
    
    RenderTable --> SearchBar["Fiscal pode pesquisar por CPF, Nome, Fornecedor ou Protocolo"]:::stepClass
    SearchBar --> TableUpdate["Tabela filtra os resultados na tela em tempo real"]:::stepClass
    
    TableUpdate --> ClickView["Fiscal clica no botão 'Abrir Ficha de Fiscalização' de uma linha"]:::stepClass
    
    ClickView --> FetchDetail["Angular faz requisição GET do registro completo por Protocolo"]:::actionClass
    
    FetchDetail --> GAS_Row["Apps Script localiza a linha exata correspondente na Planilha"]:::actionClass
    GAS_Row --> ReturnDetail["Retorna o JSON completo com os 27 dados higienizados"]:::actionClass
    
    ReturnDetail --> RenderFicha["Angular renderiza a Ficha de Fiscalização Oficial do Procon"]:::stepClass
    
    RenderFicha --> Triage["Fiscal realiza a Triagem e a Fundamentação Jurídica manual"]:::stepClass
    
    Triage --> ClickPrint["Fiscal clica no botão 'Imprimir Ficha'"]:::stepClass
    
    ClickPrint --> BrowserPrint["Navegador abre janela de Impressão"]:::actionClass
    
    BrowserPrint --> PrintOutput(["Ficha impressa em papel ou salva em PDF de alta qualidade"]):::actionClass
